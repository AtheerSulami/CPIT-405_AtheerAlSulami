01 / WEB CRAWLING & DATA AUTOMATION

Etimad

Making government prequalification opportunities easier to find, organize, and review.

FROM WEB RECORDS TO A CLEAR REPORT

Collect. Clean. Export.

  1. 01DiscoverRead the qualification data returned by the Etimad website.
  2. 02OrganizeCollect pages, remove duplicate records, and sort submission deadlines.
  3. 03ReportExport eligible opportunities to an Excel workbook.

EXCEL REPORT FIELDS

  • Project name
  • Government entity
  • Publish date
  • Submission deadline
  • Remaining days

An illustrated overview of the crawler's workflow.

The project

A Python crawler that collects prequalification opportunities from Etimad and turns them into a structured Excel report. Playwright reads the website's data responses, while pandas prepares the records for export.

The script paginates the results, removes duplicates, and keeps opportunities with at least four days left before submission. Sorting by deadline helps reviewers see which opportunities need attention first.

  • Python
  • Playwright
  • pandas
  • openpyxl
Focus
Web crawling and data preparation
Output
A structured Excel report
Key features
Pagination, duplicate removal, deadline filtering, and export

Nawras

A clearer journey for marine recreation and fishing permits.

One request. A traceable record.

  1. 01RequestEnter applicant details and a trip date.
  2. 02Validate & saveCheck the information and create a permit record.
  3. 03Review & manageView permit details or update an active permit's trip date.

STATUS FOLLOWS THE TRIP DATE

Active
Trip date is today or in the future.
Expired
Trip date has passed; date changes are restricted.

An illustrated overview of the Java implementation.

The project

A team project for managing permits for marine recreation and fishing, developed in collaboration with Jeddah Municipality. My work connected UI/UX design and system analysis with the permit application workflow.

I also contributed to the Java implementation, including permit requests, saving records, and the permit model. The repository includes a console application for requesting permits, viewing details, listing records, and updating active permits, with file storage and JUnit tests.

  • JUnit
