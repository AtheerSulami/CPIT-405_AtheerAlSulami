# مشروع CPIT-405_AtheerAlSulami — Lab 1 وLab 2

## فتح المشروع

افتحي `CPIT-405_AtheerAlSulami/index.html` مباشرة في المتصفح. افتحي Lab 1 أو Lab 2 من روابط الصفحة الرئيسية. الصورة محفوظة داخل المشروع؛ لا تحتاج إلى اتصال بالإنترنت لتظهر. روابط موقع المقرر تحتاج إلى الإنترنت.

```text
CPIT-405_AtheerAlSulami/
├── index.html
└── Labs/
    ├── labs.html
    ├── lab1.html
    ├── lab2.html
    └── kau-logo.png
```

ملف `kau-logo.png` هو شعار جامعة الملك عبدالعزيز المرفق، ويظهر في Lab 2. النقر عليه يفتح https://www.kau.edu.sa/en. الصفحات مكتوبة بـ HTML فقط دون JavaScript أو أطر عمل.

## ما تم تجهيزه

- الصفحة الرئيسية والتنقل بين جميع الصفحات.
- Lab 1: صفحة بالاسم داخل عنصر h1.
- Lab 2: العنوان المطلوب، رابط المقرر، فقرتان وبينهما فاصل، صورة قابلة للنقر مع نص بديل، خمس فقرات تتضمن كل منها عناصر تنسيق النص الخمسة، تسلسل العناوين، القوائم الثلاث، الجدول، ونموذج الدخول.
- نموذج الدخول تمرين على HTML فقط؛ يعيد فتح الصفحة ولا ينفذ تسجيل دخول. حقل كلمة المرور لا يرسل قيمته ضمن الرابط.
- استُبعدت خطوات ngrok وPostman بناءً على طلبك.

## إكمال Lab 1 على جهازك

1. ثبتي Visual Studio Code من https://code.visualstudio.com/ إن لم يكن موجودًا.
2. افتحي مجلد `CPIT-405_AtheerAlSulami` في VS Code.
3. من Extensions ثبتي Live Server من الناشر Ritwick Dey.
4. اضغطي بالزر الأيمن على `index.html` واختاري Open with Live Server.
5. التقطي صورة للشاشة يظهر فيها الاسم وعنوان الصفحة المحلي.
6. ثبتي Git من https://git-scm.com/ إذا لم يكن موجودًا.

لم يتم تثبيت البرامج أو إضافة Live Server أو تشغيله بالنيابة عنك. فتح الملف مباشرة يكفي لمشاهدة الصفحات، لكن صورة Live Server جزء مستقل من متطلبات اللاب.

## النشر والتسليم

### Lab 1

1. في حسابك على GitHub أنشئي مستودعًا باسم `cpit-405-lab-1`.
2. ارفعي **محتويات** مجلد `CPIT-405_AtheerAlSulami`: يجب أن يكون `index.html` في جذر المستودع وإلى جانبه مجلد `Labs`.
3. افتحي Settings ثم Pages. اختاري Deploy from a branch، ثم الفرع الذي رفعتِ إليه الملفات (عادة main)، والمجلد / (root)، ثم Save.
4. بعد انتهاء النشر افتحي رابط Visit site الذي يظهر في GitHub وخذي صورة للشاشة.
5. احتفظي بصورتي التشغيل المحلي والنشر لتسليم Lab 1.

### Lab 2

1. أنشئي مستودعًا جديدًا، مثل `cpit-405-lab-2`.
2. ارفعي محتويات المشروع بنفس البنية كاملة حتى تظل روابط الرجوع والصورة تعمل.
3. فعّلي GitHub Pages بالطريقة نفسها.
4. من الموقع المنشور افتحي Lab 2، وانسخي رابط الصفحة الذي ينتهي بـ `/Labs/lab2.html` لتسليمه.

لم يتم إنشاء مستودعات أو نشر الموقع؛ هذه خطوات متبقية في حسابك. لا تعدّ الملفات المحلية وحدها إكمالًا لمتطلبات النشر والتسليم.
